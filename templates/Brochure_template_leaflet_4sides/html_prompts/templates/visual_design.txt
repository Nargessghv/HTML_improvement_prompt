BROCHURE TEMPLATE - HTML VISUAL DESIGN SPECIFICATIONS:

BROCHURE COLOR PALETTE:
- Primary: White- Headlines and call-to-action elements
- Secondary: White - Subheadings and secondary information
- Body Text: White - Main content text
- Accent: light purple - Supporting elements and dividers
- HTML Background: ALWAYS TRANSPARENT - For seamless brochure integration
- Component Backgrounds: ALWAYS TRANSPARENT

BROCHURE HTML TYPOGRAPHY:
- Display Font: 'Helvetica Neue', Helvetica, Arial, sans-serif
- Heading Hierarchy:
  - H1: 32px (text-4xl), bold, White - Major sections
  - H2: 24px (text-2xl), semibold, White - Subsections
  - H3: 18px (text-lg), medium, White - Points
- Body: 14px (text-sm), regular, White - Compact for brochures
- Fine Print: 12px (text-xs), regular, White

BROCHURE HTML COMPONENTS:
- Info Boxes: No borders and transparent containers with icon headers
- Feature Lists: Checkmark icons with light blue or green accents

BROCHURE VISUALIZATION STYLE:
- Infographics: Bold, simple icons with minimal text
- Statistics: Large numbers with descriptive labels
- Process Steps: Numbered circles connected by lines
- Comparison Tables: Alternating row colors for readability
- Maps/Locations: Simple pin markers with labels

BROCHURE LAYOUT APPROACH:
- Compact, very light information design
- large padding for easy reading

BROCHURE-SPECIFIC HTML RULES:
- Optimize for print-like appearance
- Use large fonts for easy to read
